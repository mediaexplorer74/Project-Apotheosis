# Project_Apotheosis v0.1.8.5 - dev branch 

## О проекте 

Это мой форк Project-Apotheosis (проект-Апофеоз версии 0.1.8.5) от Jimmy Xiao2009.

Будет представлен**WebKit/WebCore*****windows10mobile*arm32·uwp*********************
Вернет экосистему Windows phone, от которой отказалась Microsoft, и которая сможет запускать реальные веб-страницы с помощью JIT.Современный движок рендеринга для синтеза на GPU.

>Перенесите современный движок рендеринга WebKit/WebCore на Windows10mobile (ARM32, UWP)** —
>Верните настоящий браузерный движок с ускорением JIT и графическим процессором на заброшенную платформу Windows Phone.

## Статус

Компьютер (Lumia, ARM32, Windows10, Mobile 15254):

-С** курсом WTF+JavaScriptCore**CLoop (этап 0)
-***Программный рендеринг WebCore+Cairo** -Корректный рендеринг реальных сайтов, таких как Bing/Censor / Apple/Micro и т.д.
-***Резидентный интерактивный сеанс ** - переадресация событий с помощью мыши (переход по щелчку / форме / ссылке), отложенная загрузка с помощью прокрутки, ввод с экранной клавиатуры
 Контейнер приложения после защиты возможности короткой "генерации кода" запускается и генерируется машиной jscjit.
--УГОЛ(D3D11FL9_3)+WebCore**TextureMapper**, УГОЛ...угол,
-*** Плавная прокрутка / размытый масштаб (M3/M4) **-прямой рендеринг, быстрая прокрутка + масштабирование в реальном времени + изменение сетки в новом масштабе
-Изменен пользовательский интерфейс на Safari /edge shape
