## Root causes fixed (3 distinct crashes)

### 1. cairo FT path crash (font init, "WebCore+0x0")
Mechanism (confirmed by dump analysis + disassembly): cairo objs in WebCore.dll are compiled with
mixed dllimport (`__imp_cairo_*`); functions not defined locally in the DLL link and not exported
(only ~9 of the needed 101 cairo functions were exported) got IAT slots pointing at the module base
(MZ header) -> first call (cairo_font_options_hash during cairo_scaled_font_create) = jump to base = 0xc0000005.

Fix:
- `Src/port/webcore-exports.def`: added the 27 missing cairo exports (cairo_font_options_hash,
  cairo_font_options_equal, cairo_save/translate/scale/restore, cairo_stroke, ...).
- `Src/port/link-webcore-dll.ps1`: added libEGL.lib + psl.lib (were missing from the link).
- Relinked WebCore.dll (47,446,528 B) + regenerated WebCoreFull.lib from current objs (963).

### 2. Text break iterator crash (ICU, RELEASE_ASSERT(m_iterator) -> abort 0xc0000409)
Mechanism: `TextBreakIteratorICU.h` does `RELEASE_ASSERT(m_iterator)` when `ubrk_open()` returns
null. The appx shipped a **stub `icudt75.dll` (35 KB, only root data)** which ICU prefers over the
full `icudt75l.dat` (30 MB) -> no break rules -> ubrk_open fails.

Fix:
- Built a real ICU-75 data DLL: `#embed "icudt75l.dat"` compiled with clang-cl -> lld-link
  `/dll /noentry` -> `C:\icu-x64-uwp\bin\icudt75.dll` (30,732,800 B, exports icudt75_dat).
- Harness MainPage.xaml.cpp sets `ICU_DATA=<package dir>` in SetupRuntimeEnv (points to the
  DIRECTORY; ICU appends the file name).
- vcxproj packages the real icudt75.dll (content item restored).

### 3. FontPlatformData robustness (defensive, in WebKit source)
`WebKit/Source/WebCore/platform/graphics/FontPlatformData.cpp` (WK_WINUWP ctor):
- FT face setup now also does FT_Set_Pixel_Sizes + FT_Select_Charmap before creating the cairo face.
- After `cairo_scaled_font_create`, `cairo_scaled_font_status()` is checked; on any error the scaled
  font is rebuilt from the guaranteed-safe toy face (twin backend). NaN-size guard added.
